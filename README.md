# collection

Samuel Spencer's project archive. Built with Astro.

## Add a project
1. Open `docs/project-template.md` and copy everything.
2. In `src/content/projects/`, create a new file such as `my-project.md` and paste.
3. Fill in the top section and the headings below it. Delete any heading you do not need.
4. Create the folder `src/assets/projects/my-project/` and upload `cover.jpg` and your other photos.
5. Point `cover:` and each gallery `src:` at those files, then commit. The site rebuilds in a few minutes.

## Replace a placeholder photo
Upload a photo into the project's folder and change the file name in the project's .md file.

## Change the name, Instagram link, or email
Edit `src/site.ts`.
